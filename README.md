# Atheniks Career Copilot

Interactive mock of the job search. No backend, no live listings, no real AI. Demo state stays in the browser.

## Flow

1. Search a role and city, for example Software Engineer in Berlin.
2. Review a sample profile, or enter one yourself, then set job preferences.
3. Sign in to open the workspace. The sidebar stays on Overview, Discover jobs, saved jobs, applications, and a job posting.
4. Filter from the jobs page. Signed in, filters open in a side panel so the list keeps the width.
5. The overview shows sample matches, saved roles, and applications in progress.

Reset the demo under Settings.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
